# 🛒 Ecommerce en Python (Consola)

## 📌 Descripción

Este programa simula un sistema básico de ecommerce ejecutado en consola.
Permite visualizar un catálogo de productos, buscar productos, agregarlos a un carrito de compras y calcular el total a pagar.

---

## ⚙️ Funcionalidades

* Ver catálogo de productos
* Buscar productos por nombre o categoría
* Agregar productos al carrito
* Ver carrito con detalle y total
* Vaciar carrito

---

## 🧱 Estructura

* **Catálogo**: lista de diccionarios con productos
* **Carrito**: lista de diccionarios con:

  * producto
  * cantidad

---

## 🔁 Lógica del programa

El programa utiliza un ciclo `while` para mostrar un menú principal que permite al usuario elegir distintas opciones.

Se utilizan estructuras como:

* `if / elif / else` → para controlar opciones
* `for` → para recorrer productos y carrito
* funciones → para modularizar el código

---

## ▶️ Cómo ejecutar

1. Abrir la terminal
2. Ubicarse en la carpeta del proyecto
3. Ejecutar:

```bash
python ecommerce_m3.py
```

---

## 🧠 Tecnologías usadas

* Python 3
* Tipos de datos: `int`, `str`, `float`, `bool`
* Estructuras: listas y diccionarios
